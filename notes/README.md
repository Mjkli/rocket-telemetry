# Rocket Telemetry Notes

I will create a new note for each major component in this project and document my thought process as I work through the design and implementation.

Each note will:
- explain the purpose of the component
- capture my reasoning and design decisions
- list key questions, tradeoffs, and risks
- track how the plan evolves over time
- include a timestamp for each entry so the progression is easy to follow

## Structure

Each component note will be written as a running log of my thinking, with entries added over time. The timestamp on each section will show when a decision, idea, or revision was made so the evolution of the design is preserved.
